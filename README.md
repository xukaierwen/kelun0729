# 智能预算平台

## 项目简介

智能预算平台是一个面向医药企业的全流程预算管理系统,涵盖从AI销售预测、预算编制审批到预实分析的完整业务闭环。

## 技术栈

### 前端
- **框架**: React 18
- **构建工具**: Vite 6
- **UI组件库**: Ant Design 5
- **图表库**: Ant Design Charts
- **路由**: React Router 6
- **状态管理**: Zustand
- **HTTP客户端**: Axios
- **Excel处理**: xlsx

### 后端
- **运行时**: Node.js
- **框架**: Express
- **数据库**: SQLite (开发环境) / MySQL/PostgreSQL (生产环境)
- **文件上传**: Multer

## 功能模块

### 一、基础支撑模块
1. **统一工作台** - 角色个性化看板、快捷入口、消息通知
2. **系统公共配置** - 参数配置、审批流程、字典管理
3. **Excel导入导出组件** - 通用模板配置、字段显隐、批量导入

### 二、主数据管理模块
1. **组织架构主数据** - 层级管理、虚拟Entity、业务员归属
2. **产品主数据** - 产品档案、转换系数、产品架构
3. **辅助业务主数据** - 客户档案、价格库、费用政策
4. **主数据自动同步** - SAP/管报数据源配置

### 三、AI销售预测引擎模块
1. **预测参数配置** - 周期、影响因子、维度筛选
2. **一键预测执行** - 异步运算、结果预览、多版本保存
3. **参考目标生成** - 年度/半年度/月度三大场景自动组装
4. **预测版本管理** - 版本对比、差异量化

### 四、预算编制与审批核心模块
1. **年度预算编制** (10月场景)
2. **半年度预算调整** (7月场景)
3. **月度滚动微调** (常态化)
4. **分业务类型模板管理** - 8-9套基础模板+自定义扩展
5. **版本全生命周期管理** - 多版本存储、差异对比、修改溯源

### 五、预实分析&监控模块
1. **三口径对比分析** - 预算/实际/AI预测
2. **经营看板** - 管理层汇总指标
3. **异常预警中心** - 自动抓取异常、穿透查明细

### 六、权限&用户管理模块
1. **角色管理** - 预置角色+自定义角色
2. **交叉数据权限** - 区域+产品双维度隔离

### 七、日志&审计模块
1. **全链路操作日志** - 数据修改、导入导出、提交审核留痕
2. **检索查询** - 按人员/日期/单据检索

## 快速开始

### 环境要求
- Node.js >= 20.0.0
- npm >= 10.0.0

### 安装依赖

```bash
# 前端
cd frontend
npm install

# 后端
cd backend
npm install
```

### 启动开发服务器

```bash
# 启动后端服务 (端口 8000)
cd backend
npm run dev

# 启动前端服务 (端口 3000)
cd frontend
npm run dev
```

### 访问应用
- 前端: http://localhost:3000
- 后端API: http://localhost:8000
- 健康检查: http://localhost:8000/api/health

## API接口设计

### 基础路径
- `/api/workbench` - 工作台相关
- `/api/master-data` - 主数据管理
- `/api/forecast` - 预测引擎
- `/api/budget` - 预算编制
- `/api/analysis` - 预实分析
- `/api/auth` - 权限管理
- `/api/logs` - 日志审计

## 开发规范

### 代码规范
- 使用 ES6+ 语法
- 组件使用函数式写法 + Hooks
- 统一使用 async/await 处理异步
- 遵循 RESTful API 设计规范

### 提交规范
- feat: 新功能
- fix: 修复bug
- docs: 文档更新
- style: 代码格式调整
- refactor: 重构
- test: 测试相关
